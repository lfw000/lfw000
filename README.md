# ¡Hola! Soy Luis

Desarrollador de software enfocado en el desarrollo backend, mi interés actual se centra en Java y Spring Boot.

Me interesa diseñar APIs confiables, construir sistemas mantenibles y aplicar buenas prácticas de ingeniería de software. También estoy ampliando mi experiencia con TypeScript y su ecosistema.

## Tecnologías

* **Backend:** Java, Spring Boot, Spring Data JPA, Hibernate.
* **Bases de datos:** PostgreSQL, SQL.
* **Mensajería y caché:** RabbitMQ, Redis.
* **Herramientas:** Git, Maven, Docker.
* **Frontend:** TypeScript, JavaScript, React.

## Proyectos destacados

### [E-commerce API](https://github.com/lfw000/ecommerce-api)

API REST para gestionar usuarios, productos, carritos de compra, pedidos y pagos. Incorpora autenticación y autorización mediante JWT, caché con Redis, limitación de solicitudes y control de concurrencia para el inventario.

**Tecnologías:** Java, Spring Boot, Spring Data JPA, PostgreSQL, Redis, Docker.

### [Authentication Service](https://github.com/lfw000/auth-service)

API de autenticación sin estado (*stateless*) con JWT y Spring Security. Incluye persistencia con PostgreSQL, manejo centralizado de excepciones y pruebas de integración con Testcontainers.

**Tecnologías:** Java 21, Spring Boot 3, Spring Security, PostgreSQL, Testcontainers.

### [Asynchronous Task Processing API](https://github.com/lfw000/task-processor)

API para procesar archivos CSV de forma asíncrona mediante RabbitMQ, con seguimiento del progreso y persistencia del estado de las tareas.

**Tecnologías:** Java 21, Spring Boot 4, PostgreSQL, RabbitMQ, Docker.

### [Flash Sale Platform](https://github.com/lfw000/flash-sale-platform)

Arquitectura distribuida de microservicios para gestionar reservas de entradas durante períodos de alta demanda. Aborda problemas de concurrencia e integridad de las reservas e incorpora procesamiento asíncrono y herramientas de observabilidad.

**Tecnologías:** Java 21, Spring Boot 4, PostgreSQL, RabbitMQ, Redis, Docker, GitHub Actions.
